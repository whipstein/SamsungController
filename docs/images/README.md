# Samsung IP Remote approval example

`samsung-ip-remote-allow.png` is the unmodified embedded approval-dialog photo
from page 2 of Samsung's [Consumer IP Control Worksheet](https://image-us.samsung.com/SamsungUS/samsungbusiness/tv-ci-resources/Samsung-IP-Control.pdf),
retrieved September 8, 2026. It shows an actual IP Remote prompt, not a Smart View
or Bluetooth pairing screen. Display appearance varies by model and firmware.

This small third-party illustration is included solely to identify the approval
step described in the user guide. Samsung's illustration and marks remain the
