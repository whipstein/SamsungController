# Samsung remote keys

The CLI accepts arbitrary key strings. This starter list is convenient, not a
validation allowlist:

```text
KEY_UP
KEY_DOWN
KEY_LEFT
KEY_RIGHT
KEY_ENTER
KEY_RETURN
KEY_HOME
KEY_MENU
KEY_VOLUP
KEY_VOLDOWN
KEY_MUTE
KEY_POWER
```

Treat unknown keys as experimental. Never automate unknown service-menu keys or
writes without an explicit safety review and opt-in.
