# SamsungController icon

`master.png` is the approved **TV + RGB sliders** concept, generated using the built-in image-generation tool during icon selection. The original artwork is preserved, including transparency. No new image generation or visual alteration was used when integrating it.

Concept: a dark-blue rounded-square app tile containing a silver television with three red, green, and blue vertical sliders. No text or Samsung logo.

Run `python3 packaging/icons/generate.py` on macOS to regenerate the committed `.icns`, multi-resolution `.ico`, and 512-pixel Linux `.png`. Release builds use these committed files and do not need image-generation tools or credentials.
